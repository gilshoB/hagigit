# הגיגית

משימות שממוינות לבד לרשימות. כותבים (או מקליטים מכפתור הפעולה באייפון), והמשימה נכנסת לרשימה הנכונה.
לכל אחד חשבון משלו, וכל רשימה אפשר לשתף עם מי שרוצים.

- **אתר / אפליקציה:** `public/` — עמוד אחד, בלי build. מתקינים מ-Safari: שיתוף ← הוספה למסך הבית.
- **שרת:** `api/` — פונקציות Vercel: `config` (הגדרות ציבוריות), `sort` (מיון עם Claude), `capture` (קיצור האייפון).
- **מסד נתונים:** `supabase/migrations/` — טבלאות, הרשאות (RLS), שיתוף, ותמונות.
- **מיון:** `public/lib/sorting.js` — קודם שם רשימה מפורש, אחר כך ניחוש חינמי לפי מילים ממשימות קודמות, ורק כשלא בטוחים — Claude.

## הקמה (פעם אחת, כ-30 דקות)

### 1. מסד הנתונים ב-Supabase

**להריץ את קובץ ה-SQL.** אם חיברת את GitHub ל-Supabase עם תיקיית `supabase` והפעלת Deploy לענף `main`, זה קורה לבד בכל push.
אחרת: **SQL Editor ← New query**, מדביקים את כל התוכן של `supabase/migrations/20260929120000_init.sql`, ולוחצים **Run**.
הקובץ בטוח להרצה חוזרת.

**כניסה:** מייל + סיסמה (עובד בתוך אפליקציה מותקנת, והאייפון זוכר את הסיסמה). אין צורך לשנות תבניות מייל — מייל האישור ומייל איפוס הסיסמה הרגילים של Supabase מספיקים.

**Authentication ← URL Configuration ← Site URL:** הכתובת של האתר ב-Vercel (אחרי שלב 2).

**המפתחות:** **Project Settings ← API Keys** (או **Data API**). צריך שלושה ערכים:
`Project URL`, `anon public`, `service_role` (סודי — רק ל-Vercel, לא לשום מקום אחר).

### 2. האתר ב-Vercel

**Add New ← Project ←** בוחרים את `hagigit` **← Import**. לא משנים הגדרות Build.
ב-**Environment Variables** מוסיפים:

| שם | ערך |
|---|---|
| `SUPABASE_URL` | Project URL |
| `SUPABASE_ANON_KEY` | anon public |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role |
| `ANTHROPIC_API_KEY` | *(לא חובה)* מפתח מ-console.anthropic.com — מפעיל מיון חכם כשהניחוש החינמי לא בטוח |

**Deploy.** אחרי שינוי משתנים צריך **Redeploy**.

### 3. בטלפון

1. פותחים את הכתובת ב-Safari, נרשמים עם מייל וסיסמה, מאשרים את המייל, ונכנסים.
2. **שיתוף ← הוספה למסך הבית.**
3. **הגדרות** (הכפתור עם השם למעלה) **← ייבוא** ובוחרים את קובץ ה-JSON מהגיגית הקודמת.
4. באותו מסך יש את **הכתובת האישית לקיצור** והוראות לכפתור הפעולה.

### 4. שיתוף

פותחים רשימה ← **שיתוף**. אפשר להוסיף לפי מייל (למי שכבר נכנס פעם אחת), או ליצור **לינק הזמנה** ולשלוח בוואטסאפ.
כל אחד רואה רק רשימות ששותפו איתו. אפשר להסיר אנשים, ומי שהוזמן יכול לצאת מרשימה.

## קיצור לכפתור הפעולה (Shortcuts)

1. **Dictate Text** — Language: Hebrew
2. **Get Contents of URL** — הכתובת מההגדרות באפליקציה. ▸ Method: **POST**, Request Body: **JSON**, שדה Text בשם `text` = **Dictated Text**
3. **Show Notification** — **Contents of URL**

התשובה היא שורה קצרה לכל משימה: `✓ חלב ← קניות`. מה שהשרת לא בטוח לגביו נשמר ב"נכנסים", והאפליקציה שואלת לאן.
לבדיקה בדפדפן: `https://<site>/api/capture?t=<token>&text=חלב`
